## 🌟 Visão Geral

Showcase digital de revestimentos nobres, pedras naturais e acabamentos de alto padrão — catálogo interativo e experiência visual refinada.

O projeto foi construído priorizando performance, manutenibilidade de código, design system consistente e padrões modernos de engenharia de software.

---

## 🚀 Principais Funcionalidades

- **Catálogo**: Catálogo digital de pedras naturais com filtros por ambiente e textura
- **Visualizador**: Visualizador de projetos realizados e inspirações arquitetônicas
- **Formulário**: Formulário para orçamentos sob medida e suporte a arquitetos
- **Otimização**: Otimização avançada de imagens de alta resolução via Next/Image
- **Interface**: Interface minimalista e sofisticada com transições elegantes

---

## 🛠️ Stack Tecnológica

O ecossistema do projeto é composto por tecnologias modernas e consolidadas:

- **Tecnologias Core**: `Next.js 15` `React 19` `Tailwind CSS` `TypeScript`
- **Estilização & UI**: Tailwind CSS, Radix UI primitives e Lucide Icons
- **Qualidade & Testes**: Linting estrito, Typecheck rigoroso e suítes automatizadas

## ⚡ Como Rodar Localmente

### Pré-requisitos
- Node.js (versão 20 LTS ou superior)
- Gerenciador de pacotes `npm`, `yarn` ou `pnpm`

### Instalação

1. Clone o repositório:
```bash
git clone https://github.com/BarujaFe1/pedra-belli-conceito.git
cd pedra-belli-conceito
```

2. Instale as dependências:
```bash
npm install
```

3. Inicie o servidor de desenvolvimento:
```bash
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) (ou a porta informada no terminal) no seu navegador.
