# Fotos reais — como trocar os visuais conceituais

Esta demo usa visuais vetoriais conceituais gerados localmente
(`components/stone.tsx`). Eles NÃO representam obras executadas.

Quando o prospect autorizar fotos reais:

1. Salve as fotos nesta pasta (`public/fotos-reais/`) com nomes claros:
   - `hero-cozinha.jpg`
   - `bancada-marmore.jpg`
   - `detalhe-borda.jpg`
2. Priorize orientação horizontal para hero e galeria.
3. Avise para substituir cada `<StoneFigure>` pelo `<Image>` correspondente.
4. Remova o selo "Imagem conceitual" de cada legenda substituída.
5. Rode `npm run build` e confira os viewports 390 / 768 / 1440.

Não baixar nem republicar fotos do Instagram/Facebook do prospect
sem autorização expressa.
